# Быстрый блокнот заявок (QuickPad)

Локальное приложение для оперативного обмена заявками и заметками между сотрудниками
в одной Wi-Fi сети. Один код на Flutter → **Android** (клиент) и **Windows** (хост/клиент).
Обмен данными — только внутри локальной сети; интернет нужен лишь для распознавания речи.

## Запуск за 5 минут

1. **Хост (Windows-ПК):** запустите `quickpad.exe` → «Это устройство — хост» → введите имя.
   Внизу экрана будет показан адрес хоста (например, `192.168.1.50:47650`).
2. **Клиенты (Android/Windows):** установите приложение → «Подключиться к хосту» →
   введите имя → «Найти» (автопоиск по сети) или введите адрес хоста вручную → «Подключиться».
3. Готово: заявки, журнал, контакты и присутствие синхронизируются в реальном времени.

> При первом старте хоста Windows спросит разрешение в брандмауэре — разрешите
> доступ для частных сетей. Порты: **47650/TCP** (данные), **47651/UDP** (автопоиск).

## Сборка

Требуется Flutter SDK 3.35+ (проверено на 3.50.1 / Dart 3.14).
Для сборки Android-пакета рекомендуется машина с ≥8 ГБ RAM
(Gradle + Kotlin + R8 при release-сборке).

```bash
flutter pub get

# Android-клиент (APK):
flutter build apk --release          # build/app/outputs/flutter-apk/app-release.apk

# Windows (хост и клиент) — собирается на Windows-машине:
flutter build windows --release      # build/windows/x64/runner/Release/

# Тесты и статический анализ:
flutter test
flutter analyze

# Иконки (после изменения assets/icon.png):
dart run flutter_launcher_icons
```

## Архитектура

Модель «хост + клиенты» (ТЗ, раздел 2). Хост — Windows-ПК: хранит базу и журнал,
выполняет эскалацию, напоминания и резервное копирование. Приложение хоста
подключается к собственному серверу по loopback — логика клиента единая.

```
lib/
  core/      константы (порты, палитра), форматирование времени, генерация id
  models/    заявка, пользователь, контакт, закрепление, журнал, настройки, перечисления
  data/      JSON-хранилище (атомарная запись), база хоста (авторитетная),
             кэш клиента (+ оффлайн-очередь), резервное копирование
  net/       протокол WebSocket, сервер хоста (HTTP+WS), автопоиск (UDP broadcast),
             клиентское подключение (переподключение, ping/pong), планировщик хоста
  services/  уведомления (Android push / Windows toast), диктовка, аудио,
             голосовые команды, идентификация устройства
  state/     AppState (центральное состояние), SettingsController (локальные настройки)
  ui/        экраны: главный, карточка, редактор, журнал, контакты, пользователи,
             настройки, онбординг, шторка голосовых команд
android/     разрешения, виджет «Быстрая заметка», MainActivity
windows/     нативный раннер (заголовок окна)
test/        юнит-тесты: модели, голосовые команды, журнал аудита, эскалация, напоминания
```

### Протокол

WebSocket `ws://<хост>:47650/ws` — JSON-сообщения (`net/protocol.dart`):
hello/welcome/snapshot, note_create/note_patch → note_upsert, pin_set/pins_order,
contact_upsert/delete, presence, notify, host_settings, ping/pong.
Аудиофайлы — HTTP: `POST/GET /audio/<файл>`. Автопоиск: UDP broadcast 47651.
Автор и время проставляются **хостом** из данных сессии — подмена на клиенте
не влияет на журнал (ТЗ, раздел 3).

### Конфликты и оффлайн

Клиент хранит полный кэш; оффлайн-правки кладутся в очередь и досинхронизируются
при возврате сети. При конфликте действует приоритет последнего изменения
на хосте; обе версии фиксируются в журнале (старое → новое по каждому полю),
участники получают уведомление (отключаемо).

## Решения по открытым вопросам (раздел 12 ТЗ)

1. **Лимит закреплённых (20):** только предупреждение, блокировки нет.
2. **Сортировка закреплённых:** перетаскивание, порядок синхронизируется между
   устройствами пользователя.
3. **Голосовые команды:** расширенный набор — «новая заявка», «покажи мои/все»,
   «сводка», «сменить статус на …», «закрепить/открепить», «напомни через …»,
   «позвонить контакту …». При неуверенности — варианты на выбор.
4. **Метки:** 8 базовых цветов + произвольный цвет (колесо/пипетка/HEX) + «нет метки».
5. **Повторяющиеся напоминания:** реализованы сразу (по умолчанию выключены, 6.5).
6. **Последняя активность:** видна всем в списке пользователей.

## Особенности платформ

- **Windows:** диктовка — встроенная системная (Win+H) прямо в поле текста;
  уведомления — всплывающие (звуком управляет ОС); запись аудио — через микрофон ОС.
- **Android:** диктовка — онлайн-распознавание (нужен интернет); локальные push
  со звуком/вибрацией; виджет «+» на домашнем экране; `tel:`-вызов из карточки контакта.
- Если broadcast запрещён в сети (VLAN, гостевой Wi-Fi) — автопоиск не сработает,
  введите адрес хоста вручную.

## Известные ограничения (к доработке при необходимости)

- Аудио прикрепляется при наличии связи с хостом; оффлайн — заявка сохраняется,
  аудио добавляется позже при редактировании.
- Хранение — JSON-файлы (расчёт на ≤20 устройств и десятки тысяч записей;
  при росте — миграция на SQLite, интерфейсы хранения уже изолированы).
- Безопасность базовая (ТЗ, раздел 11): без шифрования и паролей, сеть доверенная.
- `package:flutter/material.dart` помечен deprecated во Flutter 3.50 в пользу
  пакета `material_ui`; код собирается и работает, миграция — отдельным этапом.
